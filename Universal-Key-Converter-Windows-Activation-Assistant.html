Пошаговая инструкция

Для получения вечной цифровой лицензии выполните эти 5 шагов. Откройте Командную строку (CMD) от имени администратора:

Эта команда разом удалит старый ключ, очистит реестр и отвяжет ПК от пиратских KMS-серверов. (Появятся 3 окошка, везде нажмите "ОК").

Скопируйте и выполните эту команду. Дождитесь окна "Ключ продукта успешно установлен".

Выполните команду ниже. Откроется черное окно активатора:

  • Подождите пару секунд, пока загрузится меню.
  • Нажмите цифру 1 на клавиатуре (пункт HWID - Windows).
  • Дождитесь зеленой надписи Successful, затем закройте окно.

Эта команда покажет срок действия лицензии. При успешном выполнении Шага 3, должно появиться окно с текстом: «Постоянная активация прошла успешно» (срок годности не ограничен).

Откроет большое окно со всеми подробностями: тип лицензии, оставшееся количество минут/дней и статус системы.
